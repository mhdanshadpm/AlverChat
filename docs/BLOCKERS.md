## Icon morph and revert delay — 2026-11-14 21:45

- The last two controls in Settings → Floating Icon & Bubbles that stored a value with no consumer. `iconMorphEnabled` ("Morph to the active state, e.g. unread or call") and `iconMorphDelaySeconds` ("Revert delay", 1–30 s) now reach the dock through `OverlaySnapshot`, and `DockWindow` wears the active chat's face only while the switch is on, handing the icon back when the delay lapses. The timer restarts on each new unread, so activity holds the face and silence returns it to the idle logo or profile photo.
- Two decisions worth knowing: a live call is exempt from the revert (`showMorphedIcon`), because the icon should not stop wearing the face of someone you are talking to; and `morphRevertMs` clamps the stored byte back into 1–30 s for the same reason `dockOpacity` clamps — a restored backup can hold anything, and 0 would take the face away before it is painted.
