# Blockers and remaining gaps

- 2026-11-13: TLS WebSocket integration was deferred after three build iterations because the selected tungstenite configuration API was non-exhaustive and the transport module did not compile. The incomplete module and dependency changes were removed. Signed mDNS discovery is now active, but there is no listener or secure peer transport; the UI rejects send attempts and marks discovered peers as unavailable. Retry transport with an authenticated TLS 1.3 implementation, TOFU pinning, bounded frames, encrypted persistence/outbox integration, and loopback/two-device tests.
- The existing Tauri overlay build passed locally on macOS, but native window behavior has not been visually verified in this session. CUA reported that no desktop windows were available. Verify dragging, click-through, monitor positioning, startup, keychain access, and local-network permissions on macOS and Windows.
- The public GitHub repository and CI/release workflows exist. The GitHub API shows the workflows are enabled, but no hosted workflow run has appeared yet. Add `workflow_dispatch` to CI and dispatch it to verify Windows/macOS jobs.
- Calls/WebRTC, groups, file transfer, profile/avatar network sync, database backup/export/restore, signing/notarization, and the remaining settings integrations are not implemented. Their UI is disabled or shows unavailable states where reviewed; do not advertise these as working.
